# Excel Automation Demo

A simple Python automation example created by JAF Automation.

## Problem

A user has multiple Excel files containing similar information and needs to manually combine and clean them.

## Automation

This Python script automatically:

- Reads multiple Excel files
- Combines them into one dataset
- Removes duplicate records
- Sorts the information
- Generates a final Excel report

## Input

Multiple Excel files.

## Output

One clean and consolidated Excel file.
